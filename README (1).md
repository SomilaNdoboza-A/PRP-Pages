# Somila Ndoboza — Software Engineering Portfolio

## Publish on GitHub Pages

1. Download and extract `Somila_Ndoboza_Portfolio_GitHubPages.zip`.
2. Open your GitHub repository (recommended name: `SomilaNdoboza-A.github.io`).
3. Upload **all the files and folders inside the extracted folder** directly into the repository's top level.
4. Confirm that `index.html` is visible on the repository home page and that the `assets` folder is beside it (not inside another portfolio folder).
5. In Settings → Pages, select Deploy from a branch → `main` → `/(root)` → Save.
6. Wait for GitHub Pages to deploy, then refresh the published site.

Required structure:

```
index.html
assets/
  styles.css
  script.js
evidence/
  entrepreneurial-wil/
    01-team-charter.html
    02-user-stories.html
    03-product-backlog.html
    04-sprint-backlog.html
    05-agile-logbook.html
    06-reflection-summary.html
```

Do not upload only `index.html`; it links to `assets/styles.css` for the design and `assets/script.js` for the mobile navigation.
